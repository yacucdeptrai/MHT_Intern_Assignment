# Sprint Management Implementation Plan (FR-36 / M3-T8)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement Sprint Management (FR-36 / A11–A13) allowing project leads (Admin, PM, TEAM_LEAD) to create, update, and archive sprints, view sprint task completion rates, link tasks to sprints with composite foreign key protection, unlink tasks on sprint archive (A13), and cascade parent sprint updates to sub-tasks.

**Architecture:** Add sprint schemas in `@pm/domain`, repository statements in `@pm/db` (`sprintRepository` and `taskRepository.clearSprintBySprintIdStmt`), `sprintService` in `apps/web/app/services/project/sprint.service.ts` executing atomic batches A11, A12, and A13, route `_app.projects.$projectId.sprints.tsx` with loader and action, update 404 sweep test, and verify with unit, integration, and Playwright E2E specs.

**Tech Stack:** React Router v8, Cloudflare D1, Drizzle ORM, Zod, Vitest, Playwright

**Spec:** docs/01-srs.md (FR-36), docs/04-data-access-and-atomicity.md (A11, A12, A13), docs/05-rbac-and-workflow.md, docs/06-routes-and-actions.md

## Acceptance Criteria Mapping
- **FR-36 c1 (A11):** Project PM or TEAM_LEAD (or Admin) creates sprint with name (1–100 chars), startDate, endDate (endDate >= startDate); `SPRINT_CREATED` is audited.
- **FR-36 c2 (A15):** Allowed task editor (P8) sets/clears sprint on task that is not Done. Sub-tasks follow parent sprint; parent sprint change cascades to sub-tasks.
- **FR-36 c3:** Sprint from another project is rejected by BOTH service layer (400 "Sprint does not belong to this project") and DB composite foreign key (`fk_tasks_sprint_project`).
- **FR-36 c4 (A13):** Archiving a sprint unlinks its tasks (`sprint_id = NULL`), increments their version, and audits `SPRINT_ARCHIVED`.
- **FR-36 c5:** Project `MEMBER` receives 403 on sprint create, update, or archive.
- **RBAC & Project Invariants:** Non-member receives 404. Archived project returns 403. Stale version on sprint update returns 409.
