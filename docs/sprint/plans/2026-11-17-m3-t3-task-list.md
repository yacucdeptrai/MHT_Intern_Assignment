# Implementation Plan — M3-T3: Task List and My Tasks (FR-16)

## 1. Scope and Goals
- Implement `dates.ts` in `packages/domain/src/dates.ts` (`isOverdue`, `isDueSoon`, `isTodayPriority`) with strict `APP_TIMEZONE` interpretation (ends at 23:59:59.999 in Asia/Ho_Chi_Minh).
- Add domain unit tests in `packages/domain/test/dates.test.ts` covering boundary conditions from `docs/09 §3.5` and `P19`.
- Implement `taskRepository.listProjectTasks` and `taskRepository.listMyTasks` in `@pm/db` with filtering, pagination (50/page default), and index utilization.
- Add repository tests in `packages/db/test/taskQueryPlan.test.ts` executing `EXPLAIN QUERY PLAN` on project task listing and my tasks queries to confirm index use (`idx_tasks_project_status`, `idx_task_assignees_user`, `idx_tasks_due`).
- Implement `taskService.listProjectTasks` and `taskService.listMyTasks` in `apps/web/app/services/task.service.ts`:
  - `listProjectTasks`: checks user access, non-member 404, archived project check, joins status and assignees, computes date flags.
  - `listMyTasks`: filters by assigned user, accessible projects (Admin sees all; Member sees active memberships), status, priority, due range (`all`, `overdue`, `today`, `week`), pagination.
- Create `/my-tasks` route (`apps/web/app/routes/_app.my-tasks.tsx`) and loader (`apps/web/app/loaders/myTasksLoader.ts`).
- Update `/projects/:projectId` route (`apps/web/app/routes/_app.projects.$projectId._index.tsx`) and loader (`apps/web/app/loaders/projectTasksLoader.ts`) with URL search params filtering (`statusId`, `assigneeId`, `priority`, `sprintId`, `page`) and pagination.
- Add comprehensive action/loader and service tests covering FR-16 criteria 1–4, non-member 404, wrong role, archived project.
- Add Playwright E2E journey in `apps/web/e2e/taskList.spec.ts`.

## 2. Acceptance Criteria (FR-16)
- **FR-16 c1:** Given a user, When they open "My tasks", Then they see their non-archived assigned tasks across every project they can access, filterable by project, status, priority, and due range.
- **FR-16 c2:** Given a project member, When they open a project's task list, Then they see that project's non-archived tasks, filterable by status, assignee, priority, and sprint, and paginated 50 per page.
- **FR-16 c3:** Given filter values in the URL, When the page reloads, Then the same filters apply.
- **FR-16 c4:** Given a non-member, When they request a project task list, Then they receive 404.
